# Student Management System

A simple Java-based Student Management System that allows users to manage student records.

## Features

* Add Student
* Display Students
* Search Student
* Update Student
* Delete Student
* Exit the program

## Technologies Used

* Java
* VS Code
* Git
* GitHub

## Student Details

The system stores:

* Student ID
* Student Name
* Age
* Course

## How to Run

### 1. Compile the program

```bash
javac Student.java StudentManagementSystem.java
```

### 2. Run the program

```bash
java StudentManagementSystem
```
